# Amma Seva — Home Healthcare Portal

This repository contains the front-end source code for the Amma Seva web portal, a platform offering professional home healthcare and caregiving services.

## Development

To work locally on this project, ensure you have Node.js and npm installed:

```sh
cd frontend
npm install
npm run dev
```

## Tech Stack
- Vite
- TanStack Router & React Query
- TypeScript
- React
- Tailwind CSS
